## 빠른 시작

1. 새 폴더에 `docs/`와 `samples/`를 복사합니다.
2. Claude Code 같은 코딩 에이전트를 그 폴더에서 실행합니다.
3. [03_재현_가이드.md](03_재현_가이드.md) 3장의 프롬프트를 단계 0부터 순서대로 붙여 넣고, 단계마다 ✅ 확인 항목을 점검합니다.
4. 마지막에 5장 검증 체크리스트를 모두 통과하면 재현 완료입니다.

## 문서 간 관계

```
SRS (요구사항 ID: FR-ING-01 ...)  ──구현──▶  SDS (모듈·흐름·원문)  ──절차──▶  재현 가이드 (프롬프트·검증)
        ▲                                                                        │
        └──────────────────────── 인수 기준 AC-01~08 ◀── 검증 체크리스트 ─────────┘
```

## 유지 규칙

- 코드를 바꾸면 **SDS를 같이 고칩니다**. 특히 프롬프트, JSON 스키마, 파일 형식, 모델 카탈로그는 문서와 코드가 글자 단위로 같아야 합니다.
- 새 기능은 SRS에 요구사항 ID를 먼저 추가한 뒤 SDS에 설계를 적고 구현합니다.
