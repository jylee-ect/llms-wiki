# 샘플 문서

LLM Wiki의 ingest / query / lint를 시연하기 위한 샘플입니다.
**가상의 보안 회사 "한빛시큐어"** 기준으로 작성했고, 등장하는 회사·제품·인물·전화번호는 모두 가상입니다.

## 파일 목록

| 파일 | 형식 | 내용 |
|---|---|---|
| `01_출입통제시스템_개요.md` | Markdown | 가디언 AC-100 구성 요소, 인증 방식, 출입 기록 보관(1년), 펌웨어 v3.2.0 |
| `02_영상감시_운영가이드.txt` | Text | 비전 VMS 녹화·보관(**30일**), 관제센터 운영, 영상 반출 |
| `03_장비목록_판교연구소.csv` | CSV | 판교연구소 장비 11대 (펌웨어 버전, 고장 장비 포함) |
| `04_보안사고_대응절차.docx` | Word | 사고 등급 1~3, 대응 6단계, 증거 보존 기준(영상 **90일**) |
| `05_주간회의록_2026-09-22.html` | HTML | 보관 기간 30→90일 변경 검토, FaceID v2.0 계획, 액션 아이템 |
| `06_고객FAQ.json` | JSON | 고객 FAQ 6개 |
| `07_물리보안_제로트러스트_백서.pdf` | PDF | 제로 트러스트 원칙, AC-100 적용 사례, 남은 과제 |

## 추천 시연 순서

1. **문서 추가** 탭에서 `01` → `07` 순서로 하나씩 추가합니다. 여러 개를 한 번에 선택해도 됩니다.
   - 뒤의 문서를 추가할수록 `가디언 AC-100`, `비전 VMS`, `FaceID` 같은 페이지가 새로 생기지 않고 **기존 페이지가 보강**되는 것을 확인합니다.
2. **위키** 탭에서 페이지 간 링크와 역링크를 따라가 봅니다.
3. **질문** 탭에서 예시 질문을 던져 봅니다.
4. **점검** 탭에서 lint를 실행해 아래의 의도된 문제를 찾는지 확인합니다.

## 예시 질문

- 데이터센터 출입문에서 강제 개방이 발생하면 누가 무엇을 해야 해?
- CCTV 영상 보관 기간은 며칠이야?
- 판교연구소에서 지금 조치가 필요한 장비는?
- FaceID v2.0은 언제 어디에 먼저 적용돼?
- AC-100은 카드 복제 공격을 어떻게 막아?

## 의도적으로 넣은 문제 (lint 시연용)

| 유형 | 내용 |
|---|---|
| 모순 | 영상 보관 기간: 운영가이드·FAQ는 **30일**, 대응절차는 **90일**. 회의록에 "검토 중, 결정 전까지 30일 기준"이라고 나옴 |
| 오래된 정보 | FAQ·개요는 FaceID v1.4 기준. 회의록에 v2.0 테스트 완료와 2026-11 배포 계획이 나옴 |
| 상태 불일치 | 개요는 GC-40 최신 펌웨어를 v3.2.0으로 권장하지만, 장비목록의 판교 컨트롤러 2대는 v3.1.4 (이벤트 누락 버그 버전) |
| 장애 연쇄 | 카메라 CM-PG-103 고장으로 데이터센터 강제 개방 시 영상 팝업이 안 됨 (장비목록 + 회의록 + 운영가이드) |
